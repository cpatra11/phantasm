## The 8-step template workflow
1. **01 Brand** — Add brand (top left) → New brand → paste `drink-daily.com` → "Build brand kit". Kit card shows logo (Daily red script), colour swatches (cream/purple/red/coral/pink), type: **Forrest** for headlines, **DM Sans** for copy/labels/buttons, plus a "From the website" image strip (product photos, mixed box).
2. **02 Ads** — Image mode. Card header "Image · mixed formats · 60" (10 prompts × 6 drafts, 22 kept). Prompt card shows `Using: daily-hero-v11-en.jpg, daily-bottle-rose-frosted.png +17` reference chips and a count circle.
3. **03 UGC** — Image mode, 9:16, 6 drafts: phone-photo style, handwritten captions, no talking-to-camera.
4. **04 Ads from references** — Image mode "2 per reference", "Using: reference-*.jpg + product cutouts"; prompt "Make a Daily ad from this reference. Keep the idea." → same ad idea rebuilt in Daily's look (before/after: reference on top, Daily below).
5. **05 Feedback** — Image mode 9:16 · 2, using the ad + a reference ad as example: "Use our brand font Forrest for the headlines, like in this ad. Remove the stars." Result: before/after side by side, everything else nearly unchanged.
6. **06 Separate in layers** — **Design mode** "Design · 4:5": prompt "Make this ad editable. Every element on its own layer." Result card "Statement Seal design". Editor card: 7 layers — **Background, Picture, Logo, NO, ADDED, SUGAR, Discover Daily** — with font control (Format: Extrabold 80). Note: "Each headline line, the logo and the button are their own layers; seal, pack and background stay one image. The headline came back in a stand-in font, so we set Forrest and the logo in the editor, without a new generation."
7. **07 Formats** — Image mode, three prompt cards: 1:1 feed ("Make a 1:1 version of this banner for the feed."), 9:16 stories, 4:5 ("Make a 4:5 version…"). "Hera rebuilds the layout for it instead of cropping."
8. **08 Animate** — **Animation mode** "Animation · 1 scene": prompt "Animate this ad." using the Simple Equation design card. Note: "One ad, one scene, one film, no storyboard. Same prompt for each of the five ads. Hera keeps copy and product in place and picks the motion: text reveals, a floating product, light on water. 6 to 8 seconds, no sound." Result cards are 5 s videos labeled `▷ 0:05`.
